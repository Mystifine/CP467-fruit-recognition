## CP467 Fruit Recognition Data

Setup Guide:
Clone the project into your own directory.

Please download the dataset from:
https://www.kaggle.com/datasets/moltean/fruits

Unzip the file and drag the folder fruits-360_100x100 into the data folder.

run the following (for windows look up the equivalent on other OS):
`python -m venv venv` - creates virtual environment
`.\venv\Scripts\activate` - activates the virtual environment 
`pip install -r requirements.txt` - install all packages required

if you're working in visual studio code make sure the interperter is set to the one in the virtual environment
